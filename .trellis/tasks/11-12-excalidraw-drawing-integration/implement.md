# 实施计划

## 执行顺序

1. [ ] 通过 Yarn 选定稳定版 SDK，并用小型本地集成测试验证 React、Vite、CSP、资源路径及 SVG 导出与重新导入。扩大 UI 改动前，记录实际版本与必要的打包调整。
2. [ ] 用 Yarn 添加 SDK 和自托管资源。保持画布延迟加载，并确认阅读者打开文档时不会请求 Excalidraw 代码。
3. [ ] 增加本功能生成图片的来源标记与 SVG 场景往返处理。上传或粘贴的 Excalidraw SVG 仍为普通图片。验证内嵌图片和文件、`fetch(src, { cache: "no-store" })`、SVG 安全渲染；为场景数据损坏、缺失和结果过大添加聚焦测试。
4. [ ] 实现编辑会话与精确图片位置映射，包括斜杠菜单立即插入并持久化的空占位块、已有图目标、取消、上传失败、布局保留、目标被修改或删除、插入副本与覆盖。空占位块被删除时关闭画布、丢弃会话内未保存绘图并提示。首次成功保存原位更新同一占位块；未绘制退出后仍可双击重开。保存期间锁定画布，失败后解除锁定。测试相同 URL 的多张图片、并发对齐和缩放，以及每次成功保存只触发一次文档图片更新。
5. [ ] 仅为已保存图片的编辑会话实现按 `excalidraw-draft:<documentId>:<src>` 存储的浏览器本地草稿、七天过期、恢复、丢弃、30 秒、`pagehide` 和确认退出时写入、存储配额提示与成功保存后清理。空占位块首次保存前不持久化草稿，退出或关闭页面后丢弃未保存场景、保留占位块并重开空画布。用不依赖 UI 渲染的测试覆盖定时器、存储错误、退出前最后一次写入和元素删除后新增可能产生的 dirty 指纹碰撞。
6. [ ] 实现延迟加载的全窗口画布弹窗、Excalidraw UI 限制、语言和主题、加载及顶部状态、草稿栏、退出和冲突对话框、键盘操作、保存期间的画布锁定、素材库 `localStorage` 持久化与焦点恢复。
7. [ ] 接入斜杠菜单、空占位块显示与双击、图片工具栏、已保存图片的双击和 Enter、灯箱、只读行为、仅屏幕生效的深色样式，以及小图仍按块级图片显示的规则。验证空占位块的 Markdown/HTML 往返、只读呈现和 TikZ、diagrams.net 原有路径。
8. [ ] 接入非功能性需求：核对构建分包、service worker 对 JS 分块的按需缓存及首屏请求，特别确认 Excalidraw CSS 不会被预缓存；未打开画布时 Excalidraw 专用资源请求数须为零。用固定场景测量冷启动及绘图响应并留存报告，不设置固定毫秒门槛；验证 Safari/iOS Safari、Chrome、Firefox、Edge 和桌面应用。复用现有 Analytics 入口，将固定 Excalidraw 事件送到已配置的 Google Analytics、Matomo、Umami，并测试无配置、重复触发、隐私字段和分析服务失败。
9. [ ] 运行聚焦测试、`yarn tsc`、`yarn lint` 和相关格式检查；在网页端和桌面端验证浅色、深色及窄屏布局。检查打印和导出保持浅色、保存不会拉伸图片，并按 PRD 中的页面五类状态及 R01–R11 / A01–A11 逐项核对。

## 验证关口与回退点

- 扩大 UI 工作前先通过数据往返关口：导出 SVG → 现有附件上传 → 获取附件 → `loadFromBlob` → 恢复相同场景和文件。若失败，先解决数据契约。
- 接入弹窗前先通过事务关口：只能更新准确映射的图片；过期或已删除的目标不能被替换；插入副本不能修改原图。
- 浏览器关口必须验证真实键盘、焦点、Excalidraw 原生菜单、草稿恢复、大场景和 SVG 显示。单元测试不足以证明这些交互。
- 现有图片、TikZ、diagrams.net 测试是回归关口。若共享图片改动破坏原有行为，应回退该局部改动，并按 `source` 收窄新逻辑。
- 增加依赖后运行 `yarn install` 更新 `yarn.lock`。只有聚焦检查发现跨层风险时，才扩大测试范围。

## 实施前

- 按 `trellis-before-dev` 重新阅读 `prd.md`、`design.md` 和本清单。
- 完成 Trellis 规划审阅并取得批准后，再执行 `task.py start`。
