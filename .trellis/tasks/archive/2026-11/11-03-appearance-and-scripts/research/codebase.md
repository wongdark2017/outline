## 标题文字白底的复盘

### 1. 原因分类

分类为修改传播遗漏和视觉覆盖缺口。
标题包装器使用共用 `ContentEditable`。
文字内部的 `span` 自行设置主题底色。
修改文章父容器不能清除这项独立背景。

### 2. 先前验证的边界

先前文章边界采样没有覆盖标题文字内部。
先前黑白底图在标题下方恰好为白色单元。
标题自身白底与白色图片重合，截图未暴露该遮挡。
文字对比度合格不能证明文字背景与页面一致。

### 3. 预防机制

共享文字组件同样复用布局背景变量和主题回退。
只修改背景声明，不改填色、占位符和光标事件。
验收必须让深色图片单元位于标题下方。
同时检查非空标题、只读无标题和真正空标题。

### 4. 关联检查

已验证：9 项生产浏览器检查通过。
94 个原本为 255 的空白采样点全部变为 235。
这些像素现在与周围页面背景一致。
标题位置、字色和文字填色保持原值。
空标题占位符与聚焦光标保持正常。
390 px、深色、个人 CSS、恢复和打印均通过检查。
共享组件也用于集合名称与应用名称。
独立复核确认其原有回退与更具体的样式仍然成立。
没有全局清除其他文字、输入控件或高亮的背景。

### 5. 规范记录

约定写入现有 `frontend/component-guidelines.md`。
验收使用通用反色黑白底图与独立数据库。
本轮没有修改用户配置，也没有复制用户图片。
当前测试清单保持不变，不为 CSS 字符串增加单元测试。
本项目没有需要同步的规范模板目录。

## 背景单页与暂停配置的边界检查

用户明确选择隐藏入口、停用接口、停止运行并保留数据。
隐藏页签不足以满足这项范围。
仅设置旧脚本环境开关也不会停止 CSS 或草稿接口。

服务端卸载五个写接口和全部模块读取。
读取命令返回中性字段，不清空实际数据库记录。
前端删除运行器引用，并对旧响应做独立抑制。
预览不再接受用户 CSS 参数。
Store 和 Provider 两处都不把保存的 CSS 交给样式管理器。

已验证：21 项 API 回归与 30 项前端回归通过。
已验证：14 项生产浏览器检查通过。
验收预置工作区 CSS、三位用户的 CSS 和精确版本授权。
旧脚本环境开关明确保持为 `true`。
正常页面没有作者模块请求或脚本效果。
注入三次旧的已启用响应后，效果仍然为空。
背景上传、个人覆盖和恢复继承继续工作。
后台重新读取所有暂停字段，与验收前快照完全一致。
本轮没有修改实际用户数据库。

## 背景设置中文与提取检查

简体中文只新增 49 个本轮可见界面的键。
原中文值与其他 26 个语言目录保持原值。
英文新增 10 项，按本轮入口删除预期移除 11 项。
旧英文值没有变化。
第二次正常提取的输出字节保持一致。

最初尝试用 `background` context 区分 Cover 的封面语义。
当前 parser 的 defaultValue 会把生成键当作英文值。
实际输出出现 `Cover_background`，不能只验证提取成功。
最终改为 Fill background、Fit background、Tile background 普通源键。
中英文实际解析结果分别为正常英文与铺满、完整显示、平铺。
没有修改全局 parser 配置或手工修补英文输出。

背景保存的浏览器等待必须检查保存完成状态。
已有继承图片时，`background-image` 非空不能证明个人保存已完成。
本轮验收据此修正等待条件，没有为产品增加额外兼容分支。

## 首页整块深色遮挡的复盘

### 1. 原因分类

分类为同层修改传播遗漏和路由覆盖缺口。
Home 的 Documents 与 Collection 的 Content 是不同组件。
Home 仍独立设置主题底色，透明的页签仍只能透出这层纯色。
深色模式下，问题表现为整块深色矩形。

### 2. 先前验证的边界

集合、文章与设置页验证不能替代首页路由验证。
同一视觉结构不代表共用同一个包装器。
首页四个页签共用自己的 Documents 容器。

### 3. 预防机制

首页容器改为读取已有布局背景变量。
无图、恢复和打印事件时保留主题底色回退。
验收同时准备已浏览和自己创建的文档，覆盖四个页签。
必须在浅深色下比较真实背景像素。

### 4. 同类检查与结果

Search、Drafts、Archive、Trash 与共享列表容器没有另一处整列表底色。
Subheading 的固定标题窄条属于滚动遮罩。
输入框、图标、拖入遮罩和固定操作条均有独立用途。
本轮没有用全局透明规则清除这些功能表面。
已验证：8 项生产浏览器检查通过。
深色采样从统一的 36 变为底图对应的 33 与 53。
首页四个页签、固定滚动和 320/390 px 均通过检查。
CSS 与脚本保持暂停，没有作者模块请求。

### 5. 中文与规范记录

侧栏的 Personal 已经调用翻译，但简体中文目录缺失该键。
本轮只增加 Personal 对应的「个人」。
英文正常提取输出不变，既有中文值与其他语言字节不变。
个人集合的存储名称没有修改。
组件规范补充首页包装器与 Personal 翻译约定。
验收使用独立数据库与通用黑白图，没有复制用户图片。
本项目没有需要同步的规范模板目录。
