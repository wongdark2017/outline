# TikZ 图表：详细需求与验收附录

面向需求评审的正文见 [prd.md](prd.md)。
本文保留逐条需求、状态规则和验收条件。
需求组 `R1–R8`、81 条需求和验收组 `AC1–AC8` 保持不变。
除明确允许选择的事项外，全部条款均为本次必须满足的要求。
异常固定文案和统一显示位置见 [PRD 第 3.2.5 节](prd.md#325-异常固定文案与显示规则)。

## 1. 逐条需求

### R1. 入口与权限

- **R1.1.** 斜杠菜单中的 TikZ 项必须紧跟 diagrams.net 项。
- **R1.2.** 输入 `/tikz` 时，菜单必须筛选出 TikZ 项。
- **R1.3.** 菜单搜索必须识别以下关键词：
  `tikz`、`latex`、`tex`、`pgfplots`、`circuitikz`、`chemfig`、`commutative`。
- **R1.4.** 选择 TikZ 项时，必须打开新的编辑会话。
- **R1.5.** Electron 应用必须提供相同入口。
- **R1.6.** 读者界面不得显示 TikZ 创建或编辑控件。

### R2. 编辑对话框与无障碍操作

- **R2.1.** 创建和编辑图表必须使用同一个对话框。
- **R2.2.** 新建图表时，对话框必须显示默认 TikZ 模板。
- **R2.3.** 编辑已有图表时，对话框必须显示图片中的原始源码。
- **R2.4.** 代码区必须使用 CodeMirror 6，并提供 LaTeX 语法高亮。
- **R2.5.** 代码区必须显示行号。
- **R2.6.** 打开对话框时，焦点必须位于代码区。
- **R2.7.** 代码区必须支持撤销和重做。
- **R2.8.** Tab 导航必须可以到达代码区、「取消」和「保存」。
- **R2.9.** 桌面布局必须将代码区放在左侧，将预览区放在右侧。
- **R2.10.** 桌面对话框宽度必须为 `min(1100px, 90vw)`。
- **R2.11.** 桌面布局中的两栏必须均分可用宽度。
- **R2.12.** 两栏高度以 `60vh` 为目标，并遵守现有对话框的高度限制。
- **R2.13.** 窄屏布局必须保证代码区和对话框控件可以操作。
- **R2.14.** 预览区必须使用白色背景。

### R3. 预览时序与有效性

- **R3.1.** 原始源码连续 `600 ms` 没有变化时，必须开始编译。
- **R3.2.** 每次编译必须使用新的 Web Worker。
- **R3.3.** 编译不得阻塞代码输入或对话框关闭。
- **R3.4.** 原始源码变化时，必须取消上一次编译。
- **R3.5.** 对话框关闭或卸载时，必须取消该会话的编译。
- **R3.6.** 编译超时必须为 `10 s`，包括引擎启动时间。
- **R3.7.** 取消或超时时，必须终止 Worker，包括尚在启动的 Worker。
- **R3.8.** 加载引擎和编译期间，必须显示渲染提示。
- **R3.9.** 渲染错误或超时信息必须显示在代码区下方。
- **R3.10.** 错误区内容高度超过 `120 px` 时，必须可以滚动。
- **R3.11.** 存在上一次成功预览时，渲染和出错期间必须保留该预览。
- **R3.12.** 只有存在当前预览且没有错误时，才允许保存。
- **R3.13.** 等待输入停顿、编译和上传期间，必须禁用「保存」。
- **R3.14.** 过期的编译结果不得替换当前预览。

### R4. 保存与再次编辑

- **R4.1.** 保存时，必须通过现有附件流程上传当前预览。
- **R4.2.** 上传的 SVG 必须包含完整且未经修改的原始源码。
- **R4.3.** 源码元数据必须使用思源笔记的 `text/x-tikz` 格式。
- **R4.4.** 保存新图表时，必须在编辑器选区处插入图片。
- **R4.5.** 保存已有图表时，必须在原位置替换该图片。
- **R4.6.** 异步操作结束后，保存操作必须读取当前编辑器状态。
- **R4.7.** 图片工具栏和灯箱必须向编辑者提供 TikZ 编辑入口。
- **R4.8.** 再次打开图表时，必须还原原始源码，不得规范化文本。
- **R4.9.** 编辑图表必须保留图片对齐、标题和调整尺寸的行为。
- **R4.10.** TikZ 图片必须保留普通图片的下载和历史版本行为。
- **R4.11.** 保存成功后，必须关闭对话框，并将焦点返回编辑器。
- **R4.12.** 加载源码或上传失败时，必须显示可读的错误信息。
- **R4.13.** 上传失败时，必须保留对话框和原始源码。

### R5. 源码支持与错误说明

- **R5.1.** 对话框必须接受 `tikzpicture` 片段或完整 `.tex` 文档。
- **R5.2.** 编译必须保留 `standalone` 的 `border` 和 `margin` 选项。
- **R5.3.** 片段中的宏包和库声明必须按导言区声明生效。
- **R5.4.** 编译时，必须跳过文档所列的不受支持的 CJK 字体设置。
- **R5.5.** 已预加载宏包的选项不得造成重复加载的选项冲突。
- **R5.6.** 状态栏必须说明输入属于片段还是完整文档。
- **R5.7.** 状态栏必须列出识别到的库和跳过的宏包。
- **R5.8.** 状态栏必须说明非拉丁文字使用系统字体。
- **R5.9.** 识别到 `standalone` 留白设置时，状态栏必须显示该值。
- **R5.10.** 缺少宏包时，错误信息必须指出宏包名称。
- **R5.11.** 原始源码包含该宏包声明时，错误信息必须指出声明行号。
- **R5.12.** 错误区必须保留相关的 TeX 错误原文。
- **R5.13.** 生成编译源码时，不得改写最终保存的原始源码。

### R6. 图片兼容性与显示

- **R6.1.** 上传或粘贴兼容的思源 SVG 时，必须将其识别为 TikZ 图片。
- **R6.2.** TikZ 图片的工具栏必须隐藏普通图片的替换控件。
- **R6.3.** 暗色文档视图必须对 TikZ 图片使用 `invert(1) hue-rotate(180deg)`。
- **R6.4.** 该滤镜不得影响普通图片。
- **R6.5.** 对话框预览、HTML 导出和打印/PDF 输出必须保留浅色显示。
- **R6.6.** 带链接和不带链接的 TikZ 图片必须保留相同的来源标识。

### R7. 运行、安全与翻译约束

- **R7.1.** 引擎、TeX 宏包和字体必须作为同源静态资源发布。
- **R7.2.** 运行时编译不得依赖外部服务。
- **R7.3.** 体积较大的编辑依赖必须仅在启动 TikZ 编辑时加载。
- **R7.4.** 阅读、分享或导出文档时，不得加载 TeX 引擎。
- **R7.5.** 随项目发布的第三方资源必须保留适用的署名和许可证声明。
- **R7.6.** CSP 必须允许 `wasm-unsafe-eval`，不得新增 `unsafe-eval`。
- **R7.7.** 本功能的全部应用文案必须使用 `t()`。
- **R7.8.** 新增英文键必须通过现有翻译提取流程生成。
- **R7.9.** 本任务不得手动添加翻译字符串。

### R8. 关闭与异步操作隔离

- **R8.1.** 任意状态下，Esc、「取消」或遮罩层必须可以关闭对话框。
- **R8.2.** 关闭时，不得弹出未保存修改的确认框。
- **R8.3.** 关闭时，必须丢弃本次会话未保存的修改。
- **R8.4.** 延迟返回的加载、编译或上传结果不得重新打开已关闭的会话。
- **R8.5.** 会话取消后，延迟返回的结果不得修改文档。
- **R8.6.** 延迟返回的结果不得修改或关闭较新的编辑会话。

## 2. 对话框状态

| 状态         | 预览区                         | 「保存」                 |
| ------------ | ------------------------------ | ------------------------ |
| 等待输入停顿 | 保留上一次成功预览；没有则为空 | 禁用                     |
| 加载引擎     | 保留上一次成功预览；没有则为空 | 禁用                     |
| 编译中       | 保留上一次成功预览；没有则为空 | 禁用                     |
| 当前预览就绪 | 显示当前预览                   | 没有错误时启用           |
| 错误或超时   | 保留上一次成功预览；没有则为空 | 禁用                     |
| 上传中       | 显示本次提交上传的预览         | 禁用，并显示保存中的文案 |
| 已关闭       | 不显示对话框                   | 不提供对话框操作         |

本表汇总 `R3`、`R4` 和 `R8`。
具体行为以对应需求为准。

## 3. 验收条件

### AC1 — 入口与对话框（R1/R2）

前提：当前文档允许编辑。

- 打开斜杠菜单，确认 TikZ 项紧跟 diagrams.net 项。
- 输入 `/tikz`，确认菜单筛选出 TikZ 项。
- 选择该项，确认默认模板打开且焦点位于代码区。
- 检查全部搜索关键词和 Electron 入口。
- 检查语法高亮、行号、撤销、重做和 Tab 导航。
- 检查桌面尺寸，以及窄屏下控件是否可以操作。

### AC2 — 编译生命周期（R3/R8）

前提：对话框存在一张成功预览。

- 修改源码，确认「保存」立即禁用，覆盖 `600 ms` 等待期。
- 再次修改源码，确认上一次编译的 Worker 终止。
- 让过期编译返回，确认其结果不替换当前预览。
- 编译无限循环，确认 Worker 在 `10 s` 超时后终止。
- 在 Worker 启动完成前取消，确认 Worker 仍然终止。
- 在编译期间输入和关闭，确认界面始终响应操作。
- 制造编译错误，确认保留旧预览且「保存」保持禁用。

异常提示补充验收：

- 分别触发编译错误、超时、引擎加载失败和无效 SVG，确认文案对应 E01、E03、E04、E08。
- 确认固定文案显示在两栏下方、操作按钮上方。
- 确认错误区高度限制、换行和滚动符合第 3.2.5 节。
- 主动取消或新输入中止旧编译时，确认不显示失败提示。

### AC3 — 保存、再次编辑与导入（R4/R6；权限检查对应 R1）

前提：文档允许编辑，且对话框存在当前预览。

- 保存图表，确认编辑器选区处出现 SVG 图片。
- 刷新并再次编辑，确认还原的源码与原始源码完全一致。
- 分别从工具栏和灯箱编辑，确认保存后替换同一张图片。
- 在上传期间修改文档，确认保存使用当前编辑器状态。
- 检查图片对齐、标题、调整尺寸、下载和历史版本行为。
- 上传或粘贴兼容的思源 SVG，确认编辑入口还原其源码。
- 以读者身份打开，确认不显示 TikZ 创建或编辑控件。
- 选中 TikZ 图片，确认不显示普通图片的替换控件。

### AC4 — 源码兼容性与错误说明（R5）

前提：使用 [source-development-guide.txt](source-development-guide.txt) 中的示例。

- 分别编译片段和完整文档，确认输出符合示例。
- 检查 `standalone` 的留白设置和支持的 CJK 文字。
- 编译 `pgfplots`、`circuitikz` 和 `tikz-cd` 示例。
- 检查宏包和库声明、跳过的 CJK 设置及预加载宏包选项。
- 检查输入模式、库、跳过的宏包、字体提示和留白值。
- 添加不可用的宏包，确认错误指出原始源码中的声明行号。
- 检查 TeX 错误原文和上一次成功预览。
- 保存并再次编辑经过编译准备的输入，确认原始源码没有变化。

异常提示补充验收：

- 能定位声明时，确认 E02 插入真实宏包名和从 1 开始的原始行号。
- 无法定位声明时，确认使用 E02-F，不显示占位符或猜测行号。
- 确认固定中文提示和相关 TeX 原文同时显示。
- 仅跳过 CJK 字体设置时，确认使用状态栏提示。

### AC5 — 失败与取消（R4/R8）

前提：对话框处于新建或编辑会话。

- 模拟源码加载失败，确认显示可读的错误信息。
- 模拟上传失败，确认对话框保留原始源码并显示错误。
- 分别使用 Esc、「取消」和遮罩层关闭，确认丢弃未保存的修改。
- 在上传期间关闭，确认延迟返回的上传结果不修改文档。
- 打开较新的会话，确认旧会话的结果不修改或关闭新会话。

异常提示补充验收：

- 上传失败时，确认 E05 显示且代码、预览和原有文档图片保留。
- 请求失败或 SVG 无法读取时，确认在对话框内显示 E06。
- 缺少 TikZ 元数据时，确认显示 E07，且不填入默认模板。
- 源码未读取成功时，确认不能保存，原图不变。
- 旧会话返回异常时，确认新会话不显示该异常。

### AC6 — 生产环境运行与资源发布（R7）

前提：使用生产构建和生产 CSP。

- 打开 TikZ 编辑，确认同源 Worker 和 WASM 加载时没有 CSP 错误。
- 阻断外部网络并保留 Outline 连接，确认仍然可以编译。
- 阅读、分享和导出保存后的图表，确认没有 TeX 引擎请求。
- 检查第三方资源的署名、适用许可证和来源。

### AC7 — 显示与导出（R6）

前提：分别使用带链接和不带链接的 TikZ 图片。

- 根据 `R6.3–R6.4` 检查浅色和暗色文档视图。
- 根据 `R6.5` 检查对话框预览、HTML 导出和打印/PDF 输出。
- 保存并再次编辑两种图片，确认源码元数据完整。

### AC8 — 质量检查（R1–R8）

- 指定范围的 Vitest 测试必须通过。
- 格式、lint 和 TypeScript 检查必须通过。
- 翻译提取必须保留无关的现有词条。
- 重复提取必须得到相同的翻译目录内容。
- 生产构建必须通过。
- 依赖浏览器行为的验收项必须提供真实浏览器证据。
- 没有执行的检查不得报告为通过。
