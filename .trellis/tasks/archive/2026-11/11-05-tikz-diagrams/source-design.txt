# TikZ 图表：功能设计稿

Oct 22, 2026 · @dtykjdtr

> **状态：** 尚未实现。

## 设计概要

完成后，编辑者输入 `/tikz` 打开一个两栏对话框，左栏写 TikZ 代码，右栏在停止输入 600 ms 后显示预览；保存后文档中出现一张普通图片，选中它即可再次编辑。读者只看到图片，不加载 TeX 引擎。

本设计稿对应[《Outline 功能开发指南：TikZ 图表》](./TIKZ_DEV_GUIDE.md)中的实现。示意图使用 `zh_CN` 界面文字，尺寸和间距是示意，样式以 Outline 现有组件（`Modal`、`Button`、图片工具栏）为准。

| 设计原则 | 在界面上意味着 |
| --- | --- |
| 与 diagrams.net 一致 | 入口放在同样的位置：斜杠菜单创建，图片工具栏和灯箱编辑 |
| 不打断写作 | 渲染在后台线程，对话框始终可以输入和关闭 |
| 所见即所存 | 预览就是将要保存的 SVG；渲染中或有错误时不能保存 |
| 错误可读 | TeX 报错原文显示在代码下方，不用弹窗 |

## 用户流程

```mermaid
flowchart LR
  A["输入 /tikz"] --> B["TikZ 对话框<br/>停止输入 600 ms 后预览"]
  B --> C{"渲染成功？"}
  C -- "否：显示 TeX 错误，继续修改" --> B
  C -- "是" --> D["显示预览"]
  D -- "保存" --> E["上传 SVG"]
  E --> F["文档中的图片<br/>读者只看到图片"]
  F --> G["选中 → 编辑 TikZ"]
  G -- "读回源码" --> B
```

创建和编辑走同一个对话框；渲染失败只显示错误，用户留在对话框里继续改代码。

## 斜杠菜单入口

```text
┌──────────────────────────────────────────────┐
│ 函数图像如下：                               │
│ /                                            │
│                                              │
│ Mermaid Diagram                              │
│ Diagrams.net Diagram                         │
│ ▶ TikZ 图表                              ↵   │
└──────────────────────────────────────────────┘
```

- 名称：TikZ 图表（`t()` 翻译）
- 关键词：`tikz latex tex pgfplots circuitikz chemfig`
- 输入 `/tikz` 直接筛选到此项；回车打开对话框

新项紧跟在 Diagrams.net 之后。现有两项的标题在代码中没有用 `t()`，所以中文界面下仍是英文；TikZ 一项用 `t()`，显示为「TikZ 图表」。图标为 64×64 的 `public/images/tikz.png`。

## TikZ 编辑对话框

```text
┌─────────────────────────────────────────────────────────────────────────────────┐
│ TikZ 图表                                                                     × │
│                                                                                 │
│ ┌ ① 代码 ──────────────────────────────────────────┐ ┌ ② 预览 ────────────────┐ │
│ │1 \begin{tikzpicture}                             │ │      y                 │ │
│ │2   \draw[->] (-0.5,0) -- (3,0) node[right] {$x$};│ │      │     ___         │ │
│ │3   \draw[->] (0,-0.5) -- (0,2) node[above] {$y$};│ │      │   /     \       │ │
│ │4   \draw[thick, blue, domain=0:2.8]              │ │      │  /       \      │ │
│ │5     plot (\x, {sin(\x r) + 1});                 │ │      │ /               │ │
│ │6 \end{tikzpicture}                               │ │      ├──────────── x   │ │
│ │                                                  │ │                        │ │
│ └──────────────────────────────────────────────────┘ └────────────────────────┘ │
│                                                                                 │
│                                                             ③ [ 取消 ] [ 保存 ] │
└─────────────────────────────────────────────────────────────────────────────────┘
```

1. 代码区：CodeMirror 6 + LaTeX 高亮，行号，打开时获得焦点
2. 预览区：白色背景，停止输入 600 ms 后更新，就是将要保存的 SVG
3. 「保存」只在有预览、无错误、不在渲染中时可用

对话框宽 `min(1100px, 90vw)`，两栏各占一半、高 60vh。新建时代码区是默认模板，编辑时是从 SVG 读回的源码。开发指南第 10 步还在代码区下方加了一条状态栏，说明代码按「片段」还是「完整文档」编译、加载了哪些库、跳过了哪些宏包；上面的示意图没有画出它。

## 对话框状态

```mermaid
flowchart LR
  O["打开对话框<br/>首次加载约 11 MB"] -- "停顿后" --> R["渲染中<br/>显示「正在渲染…」"]
  R -- "成功" --> P["预览就绪<br/>保存可用"]
  P -- "继续输入" --> R
  P -- "点保存" --> S["保存中<br/>按钮「保存中…」"]
  S -- "上传成功" --> D["已插入文档<br/>对话框关闭"]
  R -- "失败或 10 s 超时" --> E["错误或超时<br/>代码下方显示报错"]
  E -- "继续输入" --> R
```

出错时保留上一张成功的预览，用户不会看到空白。保存失败也回到「错误」显示，代码不丢失；任何状态下 Esc 或「取消」都会直接关闭。

| 状态 | 右上角 | 代码下方 | 「保存」 |
| --- | --- | --- | --- |
| 渲染中 | 「正在渲染…」 | — | 禁用 |
| 预览就绪 | — | — | 可用 |
| 错误或超时 | — | TeX 报错原文（红色、等宽），最高 120 px 可滚动 | 禁用 |
| 保存中 | — | — | 禁用，文字为「保存中…」 |

## 文档中的 TikZ 图片

```text
┌────────────────────────────────────────────────────┐
│ 对齐  对齐  对齐  对齐  │ [✎ 编辑] 下载 评论 删除  │
│                                                    │
│ ━━━━━━━━ 选中的 TikZ 图片（蓝色描边）━━━━━━━━      │
│       │     ___                                    │
│       │   /     \                                  │
│       │ /                                          │
│       ├──────────── x                              │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━       │
└────────────────────────────────────────────────────┘
```

- 编辑 TikZ（铅笔图标）：打开对话框，从 SVG 读回源码
- 「替换图片」对 TikZ 图片隐藏
- 灯箱右上角有同样的按钮
- 只读用户：不显示编辑按钮，只看到普通图片

工具栏从左到右：四个对齐方式、编辑 TikZ、下载、评论、删除。未选中时，TikZ 图片与普通图片外观完全相同，也支持拖动调整大小、对齐和标题。

## 暗色模式

| 深色页面上 | 不处理 | `invert(1) hue-rotate(180deg)` |
| --- | --- | --- |
| 黑色的坐标轴和文字 | 几乎看不见 | 变成白色 |
| 彩色线条（如蓝色） | 偏暗 | 大致保持原色相 |

滤镜只作用于 `img[data-source="tikz"]`；对话框预览和 HTML/PDF 导出始终是浅色。

代价：用户在 TikZ 中指定的颜色会变成近似色，纯白填充会变成黑色。如果精确颜色很重要，可以改为给图片加白色背景底板，这一点待定。

## 交互规格

以下数值与开发指南中的常量一致（`PREVIEW_DELAY_MS`、`RENDER_TIMEOUT_MS`）。

| 项目 | 规格 |
| --- | --- |
| 预览触发 | 最后一次按键后 600 ms；新的输入会中止正在进行的渲染 |
| 渲染超时 | 10 s；超时后显示错误，保留上一张成功的预览 |
| 首次打开 | 下载约 11 MB 引擎文件，之后走浏览器缓存；期间右上角显示「正在渲染…」 |
| 「保存」可用条件 | 有预览、没有错误、不在渲染中、不在保存中 |
| 保存后 | 关闭对话框，光标回到编辑器；新图插入在光标处，编辑则原位替换 |
| 保存失败 | 对话框保持打开，错误显示在代码下方，代码不丢失 |
| 关闭 | Esc、点「取消」或点遮罩层；不保存任何改动 |
| 键盘 | 打开时焦点在代码区；Tab 在代码区、取消、保存之间切换；Ctrl/Cmd+Z 撤销代码修改 |
| 只读用户 | 不显示 `/tikz`、「编辑 TikZ」和灯箱编辑按钮 |
| 桌面端（Electron） | 与网页版相同；不像 diagrams.net 那样隐藏 |

**待定：** 是否在关闭有未保存改动的对话框时弹出确认？当前实现直接关闭。
