
用户常把 Overleaf 或本地 `.tex` 文件整段粘进对话框，里面带着 `\documentclass`、导言区和中文。第 0 步复制的 `run-tex.js` 已经能编译大部分这样的文档；这一步补上它漏掉的四种情况，并在对话框里说明代码被识别成了什么。存进 SVG 的始终是用户粘贴的原文，第 3 步的格式不变。

### 引擎已经做了什么

插件修改过的 `texify()` 在编译前会这样改写输入（`run-tex.js` 是压缩后的代码，可以搜索 `codePointAt(0)>255` 找到这一段）：

| 输入 | `texify()` 的处理 | 结果 |
| --- | --- | --- |
| `\documentclass` 所在行 | 整行删除；格式文件已预载 `\documentclass[margin=0pt]{standalone}`、`\usepackage[svgnames]{xcolor}`、`\usepackage{tikz}` | 类选项全部丢失，包括 `border` |
| `\begin{document}` 之前的内容 | 原样作为导言区 | `\usetikzlibrary`、`\usepackage`、`\def` 生效 |
| 没有 `\begin{document}` | 整段放进 `document` 环境 | 片段里的 `\usepackage` 报 Can be used only in preamble |
| 码位大于 U+00FF 的字符 | 用 `newunicodechar` 换成 `[U+XXXX]` 占位，生成 SVG 后换回原字符 | node 中的中文可以显示，字体由读者的系统提供 |
| 空行 | 删除 | 不影响绘图 |

### 还缺什么

1. `border`、`margin` 随 `\documentclass` 一起被删。用 standalone 自带的 `\standaloneconfig{border=…}` 放回导言区。
2. `ctex`、`xeCJK`、`CJKutf8`、`fontspec` 不在 `tex_files/` 中，而中文文档最常带的就是它们。引擎已经自己处理中文，注释掉这些行和 `\setCJKmainfont`、`\ctexset` 等命令即可。
3. `\usepackage[dvipsnames]{xcolor}` 与预载的 xcolor 冲突，报 Option clash。去掉这一行，`svgnames` 的颜色名仍然可用。
4. 片段中的 `\usepackage` 要先移到 `\begin{document}` 之前。这也是第 6 步默认模板能只写 `tikzpicture` 的前提。

### 新建 `app/editor/lib/tikz/prepareSource.ts`

```typescript
/** What the dialog's status bar says about the source. */
export type SourceInfo = {
  /** True when the source has its own \begin{document}. */
  isDocument: boolean;
  /** The class named by \documentclass, if any. The engine drops the line. */
  documentClass?: string;
  /** The standalone border or margin, carried over with \standaloneconfig. */
  border?: string;
  /** Libraries loaded with \usetikzlibrary. */
  libraries: string[];
  /** Packages loaded with \usepackage, after the CJK ones are dropped. */
  packages: string[];
  /** CJK font packages that were commented out. */
  skippedPackages: string[];
  /** True when the source has characters above U+00FF, such as Chinese. */
  hasWideChars: boolean;
};

export type PreparedSource = {
  /** The text passed to texify(). Never stored: the SVG keeps the original. */
  tex: string;
  info: SourceInfo;
};

/**
 * Font setup packages for CJK text. None of them ships with the engine, and
 * run-tex.js already draws characters above U+00FF itself.
 */
const CJK_PACKAGES = new Set([
  "ctex",
  "xeCJK",
  "CJKutf8",
  "CJK",
  "fontspec",
  "xunicode",
  "xltxtra",
]);

/**
 * Loaded by the engine's format as \usepackage[svgnames]{xcolor} and
 * \usepackage{tikz}. Asking again with other options is an "Option clash".
 */
const PRELOADED = new Set(["tikz", "pgf", "xcolor"]);

/** Commands that only work with the packages above. */
const CJK_COMMAND =
  /^\s*\\(?:setCJK\w*font|set(?:main|sans|mono)font|ctexset|xeCJKsetup)\b|^\s*\\(?:begin|end)\s*\{CJK\*?\}/;

const BEGIN_DOCUMENT = /\\begin\s*\{\s*document\s*\}/i;
const DOCUMENT_CLASS = /\\documentclass\s*(?:\[([^\]]*)\])?\s*\{([^}]*)\}/;
const BORDER_OPTION = /(?:^|,)\s*(?:border|margin)\s*=\s*(\{[^}]*\}|[^,]+)/;
const USE_PACKAGE = /\\usepackage\s*(\[[^\]]*\])?\s*\{([^}]*)\}/g;
const USE_LIBRARY = /\\usetikzlibrary\s*\{([^}]*)\}/g;
const PREAMBLE_ONLY = /^\s*\\(?:usepackage|usetikzlibrary)\b/;

/** Removes a TeX comment, keeping an escaped \%. */
function stripComment(line: string) {
  return line.replace(/(^|[^\\])%.*$/, "$1");
}

function splitNames(list: string) {
  return list
    .split(",")
    .map((name) => name.trim())
    .filter(Boolean);
}

/**
 * Turns what the user typed or pasted into input that run-tex.js compiles
 * the same way a local pdfLaTeX run of a standalone document would.
 *
 * @param source - a tikzpicture snippet or a full .tex document.
 * @returns the text for texify() and what was recognised in it.
 */
export function prepareSource(source: string): PreparedSource {
  const lines = source.split(/\r?\n/);
  const info: SourceInfo = {
    isDocument: lines.some((line) => BEGIN_DOCUMENT.test(stripComment(line))),
    libraries: [],
    packages: [],
    skippedPackages: [],
    hasWideChars: /[^\u0000-\u00ff]/u.test(source),
  };

  const out = lines.map((line) => {
    const code = stripComment(line);

    const docClass = code.match(DOCUMENT_CLASS);
    if (docClass) {
      info.documentClass = docClass[2].trim();
      const border = (docClass[1] ?? "").match(BORDER_OPTION);
      if (border && info.documentClass === "standalone") {
        info.border = border[1].trim();
      }
      return line; // run-tex.js removes every \documentclass line itself
    }

    if (CJK_COMMAND.test(code)) {
      return `% ${line}`;
    }

    for (const match of code.matchAll(USE_LIBRARY)) {
      info.libraries.push(...splitNames(match[1]));
    }

    if (!code.includes("\\usepackage")) {
      return line;
    }
    let dropped = false;
    const rewritten = code.replace(
      USE_PACKAGE,
      (_all, options: string | undefined, list: string) => {
        const names = splitNames(list);
        info.packages.push(...names.filter((name) => !CJK_PACKAGES.has(name)));
        const keep = names.filter((name) => {
          if (CJK_PACKAGES.has(name)) {
            info.skippedPackages.push(name);
            return false;
          }
          // Already loaded; the options would only cause an option clash.
          return !(options && PRELOADED.has(name));
        });
        dropped ||= keep.length !== names.length;
        return keep.length ? `\\usepackage${options ?? ""}{${keep.join(",")}}` : "";
      }
    );
    if (!dropped) {
      return line;
    }
    return rewritten.trim() ? `${rewritten} % ${line.trim()}` : `% ${line}`;
  });

  // Snippets: \usepackage is only allowed before \begin{document}.
  let tex: string;
  if (info.isDocument) {
    tex = out.join("\n");
  } else {
    const preamble = out.filter((line) => PREAMBLE_ONLY.test(line));
    const body = out.filter((line) => !PREAMBLE_ONLY.test(line));
    tex = [...preamble, "\\begin{document}", ...body, "\\end{document}"].join("\n");
  }

  if (info.border) {
    tex = `\\standaloneconfig{border=${info.border}}\n${tex}`;
  }

  return { tex, info };
}

/** A TeX error trimmed for the dialog, with a readable cause when known. */
export type TexProblem = {
  /** From the first "!" line to the "l.<n>" line of the log. */
  detail: string;
  /** A package named in "File `x.sty' not found". */
  missingPackage?: string;
  /** The 1-based line of the user's source that loads that package. */
  line?: number;
};

/**
 * Picks the part of a TeX log a person needs, and maps a missing package back
 * to the user's own line number. The log's "l.<n>" counts lines of the
 * prepared input, which differ from the editor's.
 *
 * @param error - the error message returned by renderTikz().
 * @param source - the source as the user typed it.
 */
export function describeTexError(error: string, source: string): TexProblem {
  const logLines = error.split(/\r?\n/);
  const start = logLines.findIndex((line) => line.startsWith("!"));
  let detail = error;
  if (start >= 0) {
    const end = logLines.findIndex((line, i) => i > start && /^l\.\d+/.test(line));
    detail = logLines
      .slice(start, end >= 0 ? end + 1 : start + 12)
      .join("\n")
      .trim();
  }

  const missing = error.match(/File `([^']+)\.sty' not found/);
  if (!missing) {
    return { detail };
  }
  const name = missing[1];
  const index = source.split(/\r?\n/).findIndex((line) => {
    const code = stripComment(line);
    return [...code.matchAll(USE_PACKAGE)].some((m) => splitNames(m[2]).includes(name));
  });
  return {
    detail,
    missingPackage: name,
    line: index >= 0 ? index + 1 : undefined,
  };
}
```

### 容易出错的地方

- **SVG 里存原文，不存 `tex`。** 如果 `embedSource()` 拿到改写后的文本，再次编辑时用户会看到多出的 `\standaloneconfig` 和被注释的行，思源插件读回的也是改写后的代码。
- **不要用日志里的行号。** `texify()` 删掉了空行，又在前面加了 `newunicodechar` 定义，日志中的 `l.<n>` 对不上编辑器的行号。所以 `describeTexError()` 从原文里找 `\usepackage` 所在的行。
- **中文字体不嵌入。** SVG 里的中文用读者的系统字体显示，不同系统的字形不同；没有中文字体的设备会显示方框。每个字占 `\phantom{xx}` 的宽度，与 10pt 正文里的中文字宽接近。
- **其他文档类也按 standalone 编译。** `ctexart`、`article` 的版面命令照常执行但不会分页，只保证 `tikzpicture` 的结果与本地一致。

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Refused to compile or instantiate WebAssembly module` | CSP 缺少 `'wasm-unsafe-eval'` | 第 4 步；代理层的 CSP 也要加 |
| `Failed to construct 'Worker'` | worker 脚本不同源（通常是用了 CDN 地址） | 用 `window.location.origin`，见第 1 步 |
| 引擎加载失败，提示解压错误 | 代理给 `.gz` 加了 `Content-Encoding: gzip` | 去掉该头，原样提供字节 |
| `LaTeX Error: File 'xxx.sty' not found` | 宏包不在 `tex_files/` 中 | 换用已支持的宏包，或从 TeX Live 取 `.sty` 压缩后放进 `tex_files/` |
| 预览中公式字体不对 | 后处理删掉了 `<style>` | 只删 `<script>` 和 `on*` 属性，见第 3 步 |
| 「编辑 TikZ」只显示默认模板 | 读取 SVG 失败（多为 S3 CORS）或图片已被替换 | 确认用了 `cache: "no-store"`；检查存储桶的 CORS |
| 更新引擎后用户仍用旧版 | `/static` 带一年 `immutable` 缓存 | 改目录名并更新 `TIKZJAX_URL` |
| 图中的中文显示为方框 | 读者设备没有中文字体；SVG 不嵌入中文字体（第 10 步） | 安装中文字体，或把这段文字写在图片外的正文里 |
