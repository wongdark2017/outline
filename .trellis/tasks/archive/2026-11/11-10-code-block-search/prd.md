# 代码块语言搜索

## Goal

让编辑代码块的用户能通过语言名、常见扩展名、简称和少量中文关键词快速找到语言，并在桌面及移动端完成选择。

## Background and confirmed facts

- 本任务依据用户提供的《代码块语言搜索：实施方案》和《代码块语言搜索.html》设计稿；本次用户指定的分支名为准。
- 工作分支是 `feat/code-block-search`，从 `origin/main` 建立，目标分支为 `main`。
- 当前语言菜单在 `app/editor/menus/code.tsx:24` 生成；只读模式在 `:63` 显示语言名称，编辑模式在 `:91` 展示全部语言子菜单。`shared/editor/lib/code.ts:29` 定义语言，`:420` 提供常用语言。
- 设计稿包含桌面菜单、移动端抽屉、搜索状态和匹配规则四个页面；实施方案明确要求移除设计稿底部的快捷键提示栏。
- 任务开始时，`cmdk` 尚未列为项目依赖。`package.json` 声明 React `^19.3.0` 和 `@radix-ui/react-dialog` `^1.1.23`。

## Requirements

1. 仅替换编辑态代码块工具栏中的语言下拉：桌面端使用可搜索弹出层，移动端使用底部抽屉。触发按钮按内容取宽度，当前语言名称保持单行。只读文档仍只显示名称。
2. 保留现有语言集合；为实施方案列出的 38 种语言添加关键词。搜索支持去首尾空格、忽略大小写和变音符号；不显示标记为兼容别名的重复语言。
3. 非空查询按六级匹配：名称或关键词完全相同、名称前缀、关键词前缀、名称词首、名称包含、关键词包含。单字符查询只使用前三档。同档内先按既有常用顺序，再按原语言列表顺序。
4. 空查询时显示「最近使用」和「全部语言」分组；没有使用记录时只显示「全部语言」。输入查询后展示平铺结果，突出名称命中区间；仅关键词命中时显示命中的关键词。当前语言有勾选标识。
5. 搜索框可清空。无结果时显示查询词和扩展名提示。打开时高亮当前语言；键盘上下键循环移动高亮，回车选中；中文输入法组合期间回车不得误选。Esc 在有查询时先清空，没有查询时关闭。每次重新打开时清空上次的查询。
6. 选中后关闭选择器、恢复编辑器焦点、更新代码块语言，并沿用现有最近使用统计。再次选中当前语言时只关闭，不执行语言命令。Mermaid 仍不计入最近使用。移动端打开抽屉时搜索框不自动聚焦。
7. 使用主题语义颜色保持明暗主题可读性；关键词提示用 `textSecondary`。移动端选项至少 48px 高、搜索框 16px，避免 iOS 自动放大。所有新增文案进入现有翻译提取流程，提供中文翻译。
8. 不显示设计稿中的底部快捷键提示栏。
9. 安装 `cmdk` 后在本次运行 Yarn 去重，使可合并的 Radix 依赖共用版本；现有 Radix 版本随之升级。对受影响的弹窗交互做回归验证。
10. 保持实现简单：复用现有浮层、抽屉和编辑器命令，只增加本功能需要的搜索函数和选择器，不扩展为通用选择器框架。

## Acceptance criteria

- [x] 输入 `ts`、`jav`、`terra`、`basic`、`script`、`shell`、`gres`、`c`、`PYTHON`、`C#`、`正则`、`纯`、`mermaid` 和 `cobol` 时，结果及顺序符合实施方案的示例，且显式传入常用语言的单元测试通过。
- [x] 空查询分组、搜索命中加粗与关键词提示、当前语言勾选、无结果提示、搜索清空按钮与桌面/移动布局符合设计稿（不含底部快捷键栏）。
- [ ] 桌面鼠标及键盘选择、Esc、中文输入法回车、焦点恢复、只读显示、明暗主题在可运行的环境中验证。
- [ ] 移动端抽屉可打开、选择语言，列表不被键盘遮挡；模拟移动尺寸至少验证打开与点击。真机键盘遮挡若当前环境不可测，记录为待用户验证。
- [x] 更换语言不会因菜单交互误把编辑选区移到文档开头；重新选择当前语言不会意外把代码块变成普通段落。
- [x] 聚焦范围的测试、TypeScript 检查、改动文件的 lint 和格式检查通过。
- [ ] 锁文件中可兼容的 Radix 描述符完成去重；现有弹窗的打开、关闭、焦点和移动端行为回归通过。

## Out of scope
