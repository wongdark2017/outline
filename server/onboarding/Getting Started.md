## 学习基础

- [x] 创建 Outline 账号
- [ ] 从左侧边栏**创建一个集合**
- [ ] 从首页或任意集合的右上角**新建一篇文档**
- [ ] 试试拖拽来嵌套和移动文档
- [ ] 分享一篇文档
- [ ] 邀请一位同事 👋
