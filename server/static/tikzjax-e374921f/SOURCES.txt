BUILD-SOURCE MAPPING LIMITATION
The immediate source ships run-tex.js, tex.wasm.gz and core.dump.gz as
prebuilt artifacts. It does not provide a verified mapping from these
artifacts to exact TikZJax/web2js/dvi2html source commits, complete build
inputs or dependency versions. The plugin worker also contains adaptations
for source preprocessing and wide-character replacement. This local copy
has not been rebuilt. Reproducibility and complete corresponding-source
availability for those artifacts have not been established. The links below
identify the upstream projects and their current notices; they do not assert
that current HEAD reproduces these pinned bytes. Deployment/publication
requires resolving that upstream source mapping and applicable obligations.
